# 모델 역할 분담

사용자 지시(2026-10-16): 총괄과 Sonnet 5.5가 작업을 나누고, 복잡한 일은 Opus 5.5, 간단한 일은 Gemini 3.8 Flash가 맡는다. 계획 구현에서 단순 코드 작성이 필요한 부분은 DeepSeek 4.1 Flash도 쓴다.

| 모델 | 맡는 일 | 맡기지 않는 일 |
|---|---|---|
| anthropic/claude-opus-5-5 (총괄) | 설계 판단, 단계 0 판정, 구현 계획, 정규 상태·트랜잭션·원본 보존 핵심 코드, 최종 검토 | — |
| anthropic/claude-sonnet-5-5 | 설계·계획의 일관성 검토, 중간 난도 구현 작업, 코드 리뷰 | 단계 판정과 범위 변경 결정 |
| openrouter/~deepseek/deepseek-flash-latest (응답 모델 deepseek/deepseek-v4.1-flash) | 인터페이스와 시험이 이미 정해진 단순 코드: 시험 보조 스크립트, 오류 코드 열거, 직렬화 구조체, CLI 인자 연결 같은 반복 작업 | 원본 보존 XML 편집, 트랜잭션·이력, 격리 정책, 클린룸 자료 경계에 닿는 코드 |
| google-antigravity/gemini-3.8-flash | 한국어 문서 표현·용어 점검, 짧은 요약 | 코드와 설계 판단 |

DeepSeek에 맡기는 작업에는 대상 파일·함수 시그니처·통과해야 할 시험을 함께 주고, 결과는 총괄이나 Sonnet이 읽고 시험을 직접 다시 돌린 뒤 받아들인다. opencode-free 경로는 OpenCode 밖 호출을 403으로 거절해(2026-10-16 확인) OpenRouter 유료 경로를 쓴다. 외부 공급자로 전송되므로 사용자 문서·개인 자료·실명이 든 공개 문서 본문을 입력으로 보내지 않고, 명세와 합성 자료만 보낸다. 응답한 실제 모델명은 작업 기록에 남긴다.
