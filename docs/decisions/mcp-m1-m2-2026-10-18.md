## ID·오류·발견 정보

- serde_json arbitrary_precision을 workspace에서 켜 큰 양·음 정수 id의 숫자 원문을 보존한다. 객체·배열·bool·소수·null id는 id:null, -32600이다.
- JSON-RPC framing/params 형식·도구 이름 문제는 프로토콜 오류다. 알려진 도구의 누락/잘못된 업무 인자·버전·경로·세션 오류는 모두 도구 결과 isError:true와 기존 진단으로 반환한다. 이 기준은 [2026 도구 오류 분류](https://modelcontextprotocol.io/specification/2026-07-28/server/tools#error-handling) 및 2025-11-25의 명확화에 맞춘다. arguments는 생략 가능하지만 명시한 경우 object여야 한다(null도 -32602).
- annotations 4종은 레지스트리 metadata에서 생성한다. 조회/명령 발견은 readOnly·idempotent, 내용 변경/이력/문서 lifecycle은 보수적으로 destructive, 그 밖은 보수적 false다. openWorldHint=false는 허용된 로컬 파일·격리 렌더러만 사용한다는 범위다.
- 스키마 변환은 schema 위치에만 적용한다. nullable type 배열은 anyOf로 표현하며 임의 JSON 값은 명시적 타입 union으로 유지한다. default·examples 데이터는 바꾸지 않는다. batch step params는 실제 입력 계약에 맞춰 object를 광고한다. 기존 text content와 structuredContent가 같은지 실제 프로세스 공통 시험 클라이언트도 단언한다.

## Panic·취소·시간 상한 결정

요청 dispatch는 catch_unwind로 감싼다. unwind가 나면 -32603을 반환하고 executor를 격리하여 이후 요청은 거절한다(ping과 EOF 종료는 가능). 부분 변경 여부를 추측해 계속 편집하지 않는다. Rust abort/OOM/stack overflow/OS signal은 catch_unwind 범위가 아니다. 강제 unwind는 단위 시험으로 주입해 확인했고, stdio 시험에서는 잘못된 입력 뒤 프로세스 생존·프로토콜 복구를 확인한다. 운영 바이너리에 panic 주입용 도구나 환경 변수는 추가하지 않았다.

**요청 전체의 강제 시간 상한은 이번 범위에서 도입하지 않는다.** SessionExecutor가 동기적이고 파일 publish·히스토리 commit이 같은 호출 안에서 실행된다. 응답만 timeout으로 먼저 돌려주고 worker를 방치하면 실패 응답 뒤 저장/편집이 완료될 수 있다. 안전한 중단에는 별도 worker 프로세스나 executor 전 구간의 협력적 취소와 publish 경계 설계가 필요하다. 렌더러의 기존 60초 한도는 유지하고, 클라이언트 측 대기 한도 이후 결과가 불명확하면 프로세스를 재시작하고 저장본을 재열어 확인한다.

initialized는 상태 전이로 처리한다. notifications/cancelled는 순차 실행 서버가 읽을 때 이미 완료된/알 수 없는 id이므로 무시하며 응답하지 않는다. 실행 도중 선점 취소는 지원하지 않는다. 알 수 없는 알림도 무응답, 알 수 없는 요청 메서드는 -32601이다.

resources/prompts는 추가하지 않았다. 문서 조회·preview artifact 도구가 이미 있고 현재 목표에 별도 URI/구독·템플릿 계약이 필요하지 않다. capability도 선언하지 않는다.

## 배포·doctor

hae-mcp doctor는 rhwp·hae-raster·bwrap 실행 권한, 글꼴/입력 디렉터리 읽기, 출력 디렉터리 읽기·쓰기(임시 파일 생성 후 삭제)를 JSON으로 보고한다. 정상은 종료 0, 누락/권한 실패는 1이다. 설정을 변경하거나 렌더러를 실행하지 않는다. 경로 점검만으로 sandbox 실행·글꼴 존재·한컴 호환을 검증했다고 주장하지 않는다. --help/--version·serverInfo는 엔진 0.2.0과 일치한다. 설치 및 네 클라이언트 연결 예시는 user-guide에 있다.
