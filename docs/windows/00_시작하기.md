# Windows 한글 확인 시작하기

이 안내서는 Linux에서 만든 HWPX 문서가 Windows의 한컴 한글에서 제대로 열리는지 확인하는 방법입니다.
프로그램을 따로 설치하거나 빌드할 필요는 없습니다.
설치된 한컴 한글로 문서를 열어 보고 결과만 적어 주시면 됩니다.

## 먼저 보기: 작업 우선순위와 예상 시간

시간이 부족하면 **[필수]** 항목만 마치고 결과를 돌려보내셔도 됩니다.

- **[필수] (약 25~35분)**
  - [ ] 0단계: 압축 풀기, `1_환경기록.bat` 및 `2_입력확인.bat` 실행
  - [ ] 1단계(필수): `s4_inputs` 문서 3종의 `0(원본)`과 `E(현재 정책)` 비교
  - [ ] 2단계(필수): `engine_inputs`의 `01`, `02` 열기와 `02` 다른 이름 저장 후 재열기
  - [ ] 4단계: `return\results.csv` 빈칸 채우기
  - [ ] 5단계: `3_결과묶기.bat` 실행 후 압축 파일 전달
- **[가능하면] (약 20~30분 추가)**
  - [ ] 1단계(추가): `s4_inputs` 문서 3종의 `A`, `B` 비교
  - [ ] 2단계(추가): `engine_inputs`의 `03`, `04` 열어서 `01`, `02`와 같은지 확인
  - [ ] 3단계(기본): 직접 만든 새 문서 3종(`01_text`, `02_table`, `03_picture`) 저장
- **[선택] (여유가 있을 때)**
  - [ ] 3단계(추가): 복잡한 문서(`04_complex`) 만들어 저장
  - [ ] 별도 작업: 한컴 SDK 분석 (`SDK_분석_안내.md` 참고)

## 0단계: 준비하기 (필수)

### 1. 압축 풀기
- [ ] 전달받은 압축 파일을 바탕화면이나 문서 폴더에 풉니다.
- [ ] 한글 파일 이름이 깨져서 보이면 **반디집(Bandizip)** 또는 **7-Zip**으로 다시 압축을 풉니다.
- [ ] 주의: `s4_inputs`와 `engine_inputs` 폴더의 원본 파일은 절대 덮어쓰지 않습니다. 저장할 때는 항상 **다른 이름으로 저장**을 사용합니다.

### 2. 자동 스크립트 실행하기
폴더 맨 위에 있는 `.bat` 파일 3개는 마우스로 더블클릭해 실행합니다.
이 스크립트들은 제품키, 라이선스키, 컴퓨터 이름, 사용자 이름, 설치 경로를 읽거나 기록하지 않습니다. 기록하는 것은 설치된 한컴 제품의 이름·버전·게시자, 글꼴 설치 여부, 기본 프린터 이름과 용지, 화면 배율입니다.

- [ ] `1_환경기록.bat`을 더블클릭합니다.
  - `return\environment_auto.txt` 파일이 자동으로 만들어집니다.
  - 추가로 `return\environment.txt` 파일을 메모장으로 열어 한글 제품명, 전체 빌드 번호(도움말 -> 한컴오피스 한글 정보), 글꼴 대체 알림 여부, 기본 프린터/용지를 간단히 적어 주시면 더 좋습니다.
- [ ] `2_입력확인.bat`을 더블클릭합니다.
  - 원본 파일이 손상되지 않았는지 `SHA256SUMS.txt`와 대조해 화면에 결과를 보여 줍니다.
- [ ] 만약 Windows 보호 화면(SmartScreen)이나 실행 정책 경고가 뜨면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.

### 3. 기본 조작과 저장 위치 익히기
작업하면서 아래 방법으로 파일을 남깁니다.

- **문서 안의 수정 위치 찾기**: 한글에서 `Ctrl + F`를 누르고 `S4 확인`을 검색합니다.
- **PDF로 저장하기**: 상단 메뉴에서 **파일 -> PDF로 저장하기**를 누릅니다. 메뉴가 없으면 **파일 -> 인쇄**에서 프린터를 **Microsoft Print to PDF**로 골라 저장합니다.
- **화면 캡처(스크린샷)**: 문제가 보이면 `Win + Shift + S`를 눌러 화면을 캡처하고 `return\screenshots` 폴더에 저장합니다.
- **다른 이름으로 HWPX 저장**: **파일 -> 다른 이름으로 저장**을 눌러 `return\resaved` 폴더에 저장합니다.

### 4. 저장 파일 이름 규칙
헷갈리지 않도록 아래 규칙에 맞춰 파일 이름을 지어 주세요.

| 종류 | 저장 폴더 | 파일 이름 예시 |
| :--- | :--- | :--- |
| 열자마자 저장한 PDF | `return\pdf` | `return\pdf\1_보도자료_E_열기직후.pdf` |
| 재저장 후 다시 연 PDF | `return\pdf` | `return\pdf\1_보도자료_E_재열기.pdf` |
| 다른 이름으로 저장한 HWPX | `return\resaved` | `return\resaved\1_보도자료_E_재저장.hwpx` |
| 엔진 출력(02) 열기 직후 PDF | `return\pdf` | `return\pdf\02_applied_열기직후.pdf` |
| 오류/깨짐 화면 캡처 | `return\screenshots` | `return\screenshots\문서이름_문제설명.png` |

## 1단계: S4 문서 확인하기 (0과 E는 필수, A와 B는 가능하면)

`s4_inputs` 폴더에는 문서 3종류(`1_보도자료`, `2_계획서`, `3_다중구역`)가 들어 있습니다.

### 파일 이름의 알파벳 뜻
- **0 (원본)**: 수정하기 전의 원래 문서입니다.
- **E (현재 엔진 방식)**: 글을 고친 문단부터 그 구역 끝까지 줄 배치 캐시를 지운 파일입니다. **현재 우리가 쓰는 방식**입니다.
- **A (과거 비교안)**: 고친 문단 하나의 캐시만 지운 과거 비교용 파일입니다.
- **B (비교안)**: 글은 바뀌었지만 옛날 줄 배치 캐시를 그대로 남겨 둔 비교용 파일입니다.

### 판단할 때 꼭 알아 둘 점
- 문장에 글을 덧붙였기 때문에 **전체 쪽수가 늘어나는 것 자체는 정상**입니다.
- 함께 들어 있는 Linux 참고 이미지(`linux_reference_png`)나 쪽수(3/21/28쪽)는 참고용일 뿐 정답이 아닙니다.
- `0(원본)` 파일에서도 똑같이 깨지거나 이상한 부분은 엔진 오류가 아니라 **원본 문서 문제**로 구분해 적습니다.
- 파일이 열리더라도 **"문서 복구" 또는 오류 안내 창**이 뜨면 무조건 통과(`O`)로 적지 마세요. 저장하기 전에 안내 창을 캡처(`Win + Shift + S`)하고 메모에 적어 주세요.

### 매 문서에서 눈으로 확인할 체크리스트
- [ ] 열 때 오류 창이나 복구 안내가 뜨는가?
- [ ] 글자가 빠지거나(누락) 안 보이는 부분이 있는가?
- [ ] 줄이나 문단이 서로 겹쳐 보이는가?
- [ ] 쪽 맨 아래쪽 글자가 잘려 보이는가?
- [ ] 표 테두리나 칸 크기가 깨지지 않았는가?
- [ ] 그림과 캡션(설명 글) 위치가 정상인가?
- [ ] 수정한 부분 뒤쪽이나 다음 구역이 이상해지지 않았는가?
- [ ] 글꼴(폰트)이 없어서 다른 글꼴로 바뀌었다는 알림이 뜨는가?

### 순서대로 따라 하기 (문서 3종 반복)
1. **필수 (`0`과 `E` 비교)**
   - [ ] `0_원본` 파일을 한글로 엽니다. 전체 쪽수를 확인하고 기준 PDF를 `return\pdf`에 저장합니다.
   - [ ] `E_구역끝캐시제거` 파일을 한글로 엽니다.
   - [ ] `Ctrl + F`로 `S4 확인`을 찾아 바뀐 문단과 그 뒤쪽, 표, 그림, 쪽 경계를 위 체크리스트대로 살핍니다.
   - [ ] 처음 연 상태 그대로 `return\pdf\문서이름_E_열기직후.pdf`로 저장합니다.
   - [ ] 한글에서 **다른 이름으로 저장**을 눌러 `return\resaved\문서이름_E_재저장.hwpx`로 저장합니다.
   - [ ] 창을 닫고 방금 저장한 `..._E_재저장.hwpx`를 다시 엽니다.
   - [ ] 처음 열었을 때와 똑같이 보이는지, 쪽수가 같은지 확인하고 `return\pdf\문서이름_E_재열기.pdf`로 저장합니다.
2. **가능하면 (`A`와 `B` 비교)**
   - [ ] `A_캐시제거`, `B_낡은캐시유지` 파일도 열어서 `Ctrl + F`로 `S4 확인` 위치를 비교합니다.
   - [ ] `A`는 가능하면 다른 이름으로 저장 후 다시 열기까지 확인하고, `B`는 화면 표시 비교부터 진행합니다.

## 2단계: 최신 엔진 출력(`engine_inputs`) 확인하기 (01·02 필수, 03·04 가능하면)

`engine_inputs` 폴더에는 최종 엔진이 실제로 만든 A4 세로 문서 4개가 들어 있습니다.
표(1x2 실선 표)와 그림이 들어 있는 시험용 문서입니다.

### 무엇이 바뀐 파일인가요?
- `01_original.hwpx`: 수정 전 원본입니다.
- `02_applied.hwpx`: 세 가지를 수정한 결과입니다.
  1. 표의 첫 번째 칸 글자를 `'셀가'`에서 `'바뀐셀'`로 변경
  2. `'평가 문단 하나'` 문단을 **가운데 정렬**하고 **줄간격 180%**로 변경 (맨 위 첫 문단은 쪽 설정용이므로 바뀌지 않는 것이 정상입니다)
  3. 작은 점 모양 원본 그림을 시험용 PNG 그림(약 51x25mm)으로 교체 (미세한 색감 차이만으로 실패로 보지 않습니다)
- `03_undo.hwpx`: 수정을 실행 취소(Undo)한 파일입니다. **`01_original.hwpx`와 바이트 단위로 완전히 같은 파일**이므로 화면도 `01`과 똑같아야 합니다.
- `04_redo.hwpx`: 수정을 다시 실행(Redo)한 파일입니다. **`02_applied.hwpx`와 바이트 단위로 완전히 같은 파일**이므로 화면도 `02`와 똑같아야 합니다.
- 참고: `linux_reference_png` 폴더의 사진은 Linux에서 **나눔고딕(NanumGothic)** 글꼴로 찍은 참고 화면입니다. 한컴 한글과 비교할 때는 글꼴 차이 때문에 줄바꿈이 조금 달라진 것인지 먼저 구분해 주세요.

### 순서대로 따라 하기
- [ ] **[필수]** `01_original.hwpx`와 `02_applied.hwpx`를 한글로 열어 표, 가운데 정렬/줄간격 180%, 그림이 잘 나오는지 확인합니다.
- [ ] **[필수]** `02_applied.hwpx`를 열자마자 `return\pdf\02_applied_열기직후.pdf`로 저장합니다.
- [ ] **[필수]** `02_applied.hwpx`를 `return\resaved\02_applied_재저장.hwpx`로 다른 이름 저장한 뒤, 닫고 다시 열어서 `return\pdf\02_applied_재열기.pdf`로 저장합니다.
- [ ] **[가능하면]** `03_undo.hwpx`와 `04_redo.hwpx`도 열어서 각각 `01`, `02`와 똑같이 보이는지 확인합니다.

## 3단계: 직접 새 문서 만들기 (가능하면 01~03, 선택 04)

기존에 가지고 계신 개인 보고서나 실명이 들어간 문서는 쓰지 마세요.
한컴 한글에서 새 문서를 만들어 아래 내용으로 작성한 뒤, **HWPX 파일과 PDF 파일 한 쌍**으로 `return\user_fixtures` 폴더에 저장해 주세요.
사용한 기본 글꼴과 용지 크기/여백도 메모해 주시면 좋습니다.

- [ ] **[가능하면] `01_text` (`01_text.hwpx`, `01_text.pdf`)**
  - 제목과 본문 3문단을 적습니다.
  - 일부 단어만 **굵게** 하거나 글꼴을 바꾸고, 한글·영문·숫자를 섞어 넣습니다.
  - 본문을 길게 복사해 **전체 2쪽 이상**이 되게 만듭니다.
- [ ] **[가능하면] `02_table` (`02_table.hwpx`, `02_table.pdf`)**
  - 셀 병합이 없는 **2x2 표**를 만듭니다.
  - 각 칸마다 한 문단씩 아무 시험용 글자나 넣습니다.
- [ ] **[가능하면] `03_picture` (`03_picture.hwpx`, `03_picture.pdf`)**
  - 본문과 함께 직접 만든 간단한 PNG 그림 하나를 넣고 캡션(설명)을 답니다.
  - 그림 자르기나 특수 효과는 넣지 않습니다.
- [ ] **[선택] `04_complex` (`04_complex.hwpx`, `04_complex.pdf`)**
  - 셀이 병합된 표, 한 칸에 여러 문단, 수식, 글상자 등을 넣습니다. (엔진이 복잡한 요소를 안전하게 보존하거나 거절하는지 시험하는 용도입니다.)

## 4단계: `return\results.csv` 작성하기 (필수)

`return\results.csv` 파일을 **Excel**로 엽니다.
각 칸에는 **`O`(정상/이상 없음)**, **`X`(문제 있음)**, **`미확인`(시간 부족 등으로 안 봄)** 중 하나와 짧은 설명을 적습니다. (쪽수 칸만 숫자로 적습니다.)
표에는 `user_fixtures` 문서 `01~04` 행이 이미 들어 있습니다. 만들지 않은 문서 행은 `미확인`으로 두시고, 추가로 만든 문서는 맨 아래 줄에 행을 추가해 적어 주세요.

- **파일**: 확인한 파일 경로입니다. (이미 적혀 있습니다.)
- **열기/복구안내**: 경고 없이 바로 열리면 `O`, 복구 안내나 오류 창이 뜨면 `X`와 안내 문구를 적습니다.
- **쪽수**: 한글 화면에 보이는 전체 쪽수를 숫자로 적습니다. (예: `4쪽`)
- **글누락/잘림/겹침**: 글자 빠짐, 아래쪽 잘림, 줄 겹침이 없으면 `O`, 있으면 `X`와 위치를 적습니다.
- **표/그림**: 표 테두리와 그림·캡션 위치가 정상이면 `O`, 깨지면 `X`를 적습니다.
- **폰트대체**: 글꼴이 정상 적용되면 `O`, 대체 글꼴 알림이 떴으면 어떤 글꼴로 바뀌었는지 적습니다.
- **재저장후재열기**: 다른 이름으로 저장 후 다시 열었을 때 모양과 쪽수가 같으면 `O`, 달라지면 `X`를 적습니다.
- **PDF/스크린샷**: 저장한 PDF나 캡처 파일이 있으면 `O`(또는 파일 이름)를 적습니다.
- **메모**: `0(원본)`에도 있던 문제인지, 특이한 점은 무엇인지 자유롭게 적습니다.

## 5단계: 결과 묶어서 돌려보내기 (필수)

- [ ] 작성한 `return\results.csv` 파일을 저장하고 Excel을 닫습니다.
- [ ] 폴더 맨 위의 **`3_결과묶기.bat`** 파일을 더블클릭합니다.
  - 스크립트가 `return\RETURN_SHA256SUMS.txt`에 `return` 폴더 안 파일의 해시를 기록하고, **바탕화면에 `Windows_결과_yyyyMMdd_HHmm.zip`**(예: `Windows_결과_20261018_1430.zip`) 압축 파일을 자동으로 만듭니다. 같은 이름이 이미 있으면 `_2`를 붙여 새로 만듭니다.
- [ ] 보내기 전 마지막 확인: 압축 파일 안에 **개인정보, 실명 문서, 한컴 제품키/라이선스키**가 들어가지 않았는지 다시 한 번 확인합니다.
- [ ] 바탕화면에 만들어진 `Windows_결과_yyyyMMdd_HHmm.zip` 파일 하나만 Linux 작업자에게 전달해 주시면 끝납니다.

## 자주 묻는 질문 (FAQ)

**Q1. 시간이 너무 부족한데 다 해야 하나요?**
아닙니다. 맨 위에 안내된 **[필수]** 항목(0단계, S4의 `0`과 `E`, `engine_inputs`의 `01`과 `02`, `results.csv` 기록, `3_결과묶기.bat`)만 진행하고 나머지 칸은 `미확인`으로 비워 둔 채 보내 주셔도 큰 도움이 됩니다.

**Q2. 제 PC의 한글 버전이 다른데 괜찮나요?**
괜찮습니다. 어떤 버전에서 확인했는지만 알 수 있도록 `1_환경기록.bat`을 실행하고, 한글 메뉴의 **도움말 -> 한컴오피스 한글 정보**에 나오는 제품명과 빌드 번호만 남겨 주세요.

**Q3. 문서를 열 때 글꼴(폰트)이 없다고 나옵니다.**
오류가 아닙니다. Linux 참고 화면은 나눔고딕 글꼴을 사용했습니다. 글꼴 대체 알림이 뜨면 어떤 글꼴이 없다고 나오는지 `results.csv`의 `폰트대체` 칸에 간단히 적어 주세요.

**Q4. 복구 안내 창이 뜨거나 파일이 안 열립니다.**
창을 닫거나 덮어쓰지 마시고, `Win + Shift + S`를 눌러 안내 창 화면을 캡처해 `return\screenshots` 폴더에 저장해 주세요. 그리고 `results.csv`의 `열기/복구안내` 칸에 `X`를 적으시면 됩니다.

**Q5. 쪽수가 Linux 참고 사진이나 원본(`0`)과 다릅니다.**
글이 추가되었거나 PC에 설치된 기본 글꼴이 다르면 쪽수가 늘어날 수 있습니다. 쪽수가 다른 것만으로는 실패가 아니니, 보이는 쪽수를 그대로 적어 주시면 됩니다.
